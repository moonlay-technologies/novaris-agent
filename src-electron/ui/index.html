Advanced collection settings

Agent mode

Network Gateway Agent adds network-wide monitoring on top of normal endpoint monitoring. Deploy it on whichever machine acts as your network monitoring point.

Syslog collector

Listens for UDP syslog messages and classifies them with the same Sigma detection rules used for local logs.

SNMP polling

Polls network devices (switches, access points, printers) for liveness and identity.

Active discovery

Ping-sweeps the local subnet and flags devices not seen before as a possible rogue device.

Zeek log tailing

Linux/macOS only. Tails notices from an already-installed, already-running Zeek - this does not install or manage Zeek itself.

Response actions

Remote actions can execute commands on this endpoint. Dry-run is the safe default.
